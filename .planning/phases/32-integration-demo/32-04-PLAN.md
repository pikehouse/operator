<task type="auto">
  <name>Task 3: Run end-to-end fault injection test</name>
  <files></files>
  <action>
1. Start the monitor to create tickets on violations:
   ```bash
   cd packages/operator-core
   python -m operator_core.cli.main monitor run --subject tikv -i 5 &
   ```

2. In another terminal, start the agent loop:
   ```bash
   docker compose -f docker/agent/docker-compose.yml up
   ```
   The agent should print "Agent loop starting" and poll every second.

3. Inject fault - kill a TiKV node:
   ```bash
   docker stop tikv0
   ```

4. Watch for:
   - Monitor detects violation and creates ticket
   - Agent picks up ticket (prints "Processing ticket #N")
   - Claude investigates (shell commands to docker ps, curl prometheus)
   - Claude diagnoses (identifies tikv0 is down)
   - Claude fixes (docker start tikv0 or similar)
   - Agent marks ticket resolved

5. If agent escalates instead of resolving, that's acceptable for first run.
   The key is that the full loop executes.
  </action>
  <verify>
Ticket created, agent processes it, audit log shows reasoning chain
  </verify>
  <done>End-to-end flow completes: fault -> ticket -> agent -> diagnosis/fix</done>
</task>
